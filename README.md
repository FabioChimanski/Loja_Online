# Loja Online - Sistema de E-commerce

Este é um projeto de uma loja online completa desenvolvida em PHP e MySQL. O sistema conta com funcionalidades essenciais para a operação de um e-commerce, incluindo gestão de produtos, carrinho de compras e um painel administrativo.

## Funcionalidades

### Área do Cliente
- **Cadastro e Login:** Sistema de autenticação de usuários.
- **Catálogo de Produtos:** Visualização detalhada de produtos disponíveis.
- **Carrinho de Compras:** Adição, remoção e gerenciamento de itens.
- **Gestão de Pedidos:** Acompanhamento do histórico e detalhes dos pedidos realizados.
- **Perfil:** Edição de dados pessoais do cliente.

### Área Administrativa
- **Dashboard:** Visão geral do sistema.
- **Gestão de Produtos:** CRUD completo (adicionar, listar, editar e excluir produtos) com upload de imagens.
- **Controle de Pedidos:** Gerenciamento e atualização do status de pedidos dos clientes.
- **Cadastro de Admins:** Criação de novos perfis com privilégios administrativos.

## Tecnologias Utilizadas

- **Linguagem:** PHP
- **Banco de Dados:** MySQL
- **Estilização:** CSS3
- **Estrutura:** HTML5
